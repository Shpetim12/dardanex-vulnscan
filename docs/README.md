# Documentation assets

This directory contains visual assets used by the project README.

- `banner.svg`: the included 1280 × 640 README banner placeholder. Replace it with a polished banner when available, keeping the artwork legible at full README width.
- `demo.svg`: the included demo placeholder. Replace it with a screenshot of a real, authorized vulnscan scan. Remove or redact target-sensitive details, API keys, credentials, and internal IP addresses before committing it.

The main README intentionally references these paths now so the images will display automatically when they are added.

# Documentation assets

This directory contains visual assets used by the project README.

- `banner.svg`: the included 1280 × 640 README banner placeholder. Replace it with a polished banner when available, keeping the artwork legible at full README width.
- `demo.png`: must be a real terminal screenshot of a finished quick scan on `scanme.nmap.org`. It must show open ports, CVE results, the HTTP header grade, and generated report paths. Remove or redact API keys, credentials, local paths, and other sensitive details before committing it.

The main README references these paths directly so the images render automatically when they are added.

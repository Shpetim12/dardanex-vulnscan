# Documentation assets

This directory contains visual assets used by the project README.

- `banner.png`: add a 1280 × 640 project banner. Keep the design legible when rendered at full README width and include the vulnscan name or visual identity.
- `demo.png`: add a screenshot of a real, authorized vulnscan scan. Remove or redact target-sensitive details, API keys, credentials, and internal IP addresses before committing it.

The main README intentionally references these paths now so the images will display automatically when they are added.

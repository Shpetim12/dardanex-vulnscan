# Security Policy

## Responsible use

vulnscan is for authorized security testing and education only. Obtain explicit permission before scanning a target, respect agreed scope and rate limits, and do not use the tool to access or disrupt systems.

## Reporting a vulnerability in vulnscan

Please do not disclose a suspected vulnerability in this tool through a public issue. Email [info@dardanex.com](mailto:info@dardanex.com) with a clear description, affected version, reproduction steps, and impact. Dardanex will review the report and coordinate a responsible disclosure.
